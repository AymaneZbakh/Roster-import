# RAM Roster Viewer

A browser-based viewer for Royal Air Maroc crew roster JSON files.

## Features
- Upload your roster JSON and view all activities (flights, standby, training, duties)
- Filter by activity type
- Expandable cards with full timeline, crew, and training details
- **Export to iCalendar (.ics)** — import directly into Apple Calendar, Google Calendar, or Outlook

## Usage
1. Open the app at your GitHub Pages URL
2. Drop or upload your roster `.json` file
3. Browse your schedule
4. Tap **Export .ics** to download your calendar file
5. Tap the downloaded file to import into Calendar

## Hosting
This is a single-file app hosted via GitHub Pages. No backend, no data leaves your device.
